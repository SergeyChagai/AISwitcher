# Architecture

Обзор. Решения и их обоснование — в [ADR](./adr/).

## Поток данных

```
Клавиатура
    │
    ▼
Перехват ввода (ADR-0003)          ─── синхронный, ничего не считает
    │  событие в очередь
    ▼
Буфер токена + окно контекста       ─── только в памяти, на диск не пишется
    │
    ▼
Генерация кандидата                 ─── карта раскладок, обратимое отображение
    │
    ▼
Tier 0: детерминированный скорер    ─── n-граммы + частотный словарь
    │
    ├── уверен ──────────────────────────────┐
    │                                        │
    └── не уверен                            │
            │                                │
            ▼                                │
    Tier 1: контекстная модель (ADR-0002)     │
            │                                │
            └────────────────┬───────────────┘
                             ▼
                   Решение + уверенность
                             │
              ┌──────────────┴──────────────┐
              ▼                             ▼
      Переключить и                   Ничего не делать
      перенабрать токен               (по умолчанию при
              │                        неуверенности)
              ▼
      Отмена одной клавишей
      → локальный словарь исключений
```

## Компоненты

| Компонент | Ответственность | Бюджет | ADR |
|---|---|---|---|
| Input interceptor | получить событие и немедленно вернуть управление | микросекунды | [0003](./adr/ADR-0003-windows-input-interception.md) |
| Context buffer | текущий токен + N предыдущих, только в RAM | — | [0003](./adr/ADR-0003-windows-input-interception.md) |
| Layout map | обратимое отображение RU ↔ EN | микросекунды | [0001](./adr/ADR-0001-two-tier-detection-pipeline.md) |
| Tier 0 scorer | оценка двух гипотез без модели | < 1 мс | [0001](./adr/ADR-0001-two-tier-detection-pipeline.md) |
| `LayoutDecider` (Tier 1) | контекстное решение, реализация сменная | десятки мс, асинхронно | [0002](./adr/ADR-0002-model-selection-for-context-disambiguation.md) |
| Actuator | переключение раскладки и перенабор | — | [0003](./adr/ADR-0003-windows-input-interception.md) |
| Exceptions store | чёрные списки и отмены пользователя | — | [0003](./adr/ADR-0003-windows-input-interception.md) |

## Инварианты

- Содержимое ввода не пишется на диск и не покидает машину.
- Обработчик хука не выполняет детекцию.
- При неуверенности действие по умолчанию — не переключать.
- Tier 1 не является обязательным для работоспособности продукта.
- Никакой код не зависит от конкретной модели напрямую — только от интерфейса `LayoutDecider`.

## Стек

Rust ([ADR-0004](./adr/ADR-0004-implementation-stack-rust.md)): `windows` для Win32, `tray-icon`
для трея, `ort` для инференса Tier 1 — последний подключается только если ADR-0002 выберет
ONNX-модель. Tier 0 обходится без внешних зависимостей.

## Не решено

- Модель Tier 1 — ADR-0002 в статусе `Proposed`.
- Один процесс или разделение хука и детекции — открытый вопрос ADR-0004.
