## Sprint 1 — Research: выбор модели

Goal: заменить гипотезу «берём e5» на измеренное решение — ADR-0002 переходит в Accepted с цифрами.

- [x] Собрать корпус: русский, английский, технический текст, код, команды (tools/build-corpus.sh)
- [x] Разметить эталон: выводится автоматически из корректного текста и его транслитерации
- [x] Реализовать baseline: карта раскладок + символьная n-граммная модель (crates/)
- [x] Замерить baseline: P=0.9986, R=0.9736, p99=24.5 мкс (margin=0.7)
- [x] Собрать контекстный подкорпус: 78 предложений, 8 семейств (corpus/context/)
- [x] Подключить корпус живой речи: OpenSubtitles ru (tools/fetch-opensubtitles.sh)
- [ ] Научить харнесс читать corpus/context: замер по семействам A-H, а не потокенно
- [ ] Добавить в Tier 0 признак регистра: заглавная в середине фразы и капслок
- [ ] Замерить кандидатов из `docs/research/model-evaluation.md`
- [ ] Проверить применимость `multilingual-e5-small` именно к этой задаче (открытые вопросы ADR-0002)
- [ ] Свести результаты в `docs/research/model-evaluation.md` и закрыть ADR-0002

Sprint 1 status: in progress — baseline и контекстный подкорпус готовы, кандидаты не замерены.

Goal: доверие пользователя как измеримое свойство.
