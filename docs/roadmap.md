## Sprint 1 — Research: выбор модели

Goal: заменить гипотезу «берём e5» на измеренное решение — ADR-0002 переходит в Accepted с цифрами.

- [x] Собрать корпус: русский, английский, технический текст, код, команды (tools/build-corpus.sh)
- [x] Разметить эталон: выводится автоматически из корректного текста и его транслитерации
- [x] Реализовать baseline: карта раскладок + символьная n-граммная модель (crates/)
- [x] Замерить baseline: P=0.9982, R=0.9731, p99=29.2 мкс на 20 269 случаях (margin=0.7)
- [x] Собрать контекстный подкорпус: 105 предложений, 612 токенов, семейства A-H
- [x] Подключить корпус живой речи: OpenSubtitles ru (tools/fetch-opensubtitles.sh)
- [x] Научить харнесс читать corpus/context: замер по семействам A-H (2 FP, 24 FN на 612 ток.)
- [x] Правило вызова Tier 1: band=2.0 — 24% решений наверх, 26 ошибок из 27 доступны модели
- [x] Проверить дешёвый контекстный признак: соседство закрыло 1 ошибку, E и H не берёт
- [x] Нарастить E и H: пары найдены прогоном find-collisions по корпусам, а не руками
- [x] Расширение вскрыло 2 ложных срабатывания (Гы -> us, кг -> ru), которых корпус не видел
- [x] Кандидат 1 — регистр текста: ОТВЕРГНУТ, меняет precision на recall, FP не чинит
- [x] Кандидат 2 — линейная модель над признаками Tier 0: ПРИНЯТ, P=1.0000 R=0.6438, FP=0
- [x] ADR-0005: персонализация и дообучение на пользователе, метрики и первый замер
- [x] ADR-0006: вопрос пользователю как третий исход — закрывает пустую петлю обучения
- [x] Свести результаты и закрыть ADR-0002: Tier 1 = линейная модель, e5 отклонён без замера

Sprint 1 status: closed.

Что осталось незакрытым и куда перенесено:

- Корпус технической русской речи. Локальные источники исчерпаны: в коммитах английский,
  комментарии в C# в смешанных кодировках. Нужен внешний источник — перенесено в Sprint 2.
- e5 как источник признаков. Отложено до задачи, где девяти признаков не хватит.
- Прототип подсказки у каретки и цена прерывания — это UI, перенесено в Sprint 3 и Sprint 4.

## Sprint 2 — Ядро детекции

Goal: вынести движок из исследовательского харнесса в пригодный к поставке вид.

Значительная часть логики уже написана и измерена, но живёт внутри `crates/eval` вперемешку
с замерами. Спринт про то, чтобы отделить продукт от исследования.

- [x] Карта раскладок RU/EN (`crates/layout-map`, обратимость под тестом)
- [x] Tier 0: генерация кандидатов и скоринг (`crates/ngram` + логика в `eval`)
- [x] Калибровка порогов под асимметричную стоимость ошибок (margin=0.7, band=2.0)
- [x] Оффлайн-прогон на корпусе как регрессионный тест
- [ ] Вынести Tier 0 из `eval` в отдельный крейт: `eval` должен остаться только замером
- [ ] Вынести Tier 1 (линейная модель) с интерфейсом, допускающим замену реализации
- [ ] Третий исход в модели решения: `Switch | Keep | Ask` вместо булева (ADR-0006)
- [ ] Сериализация весов и пословной памяти на диск (ADR-0005: веса да, текст никогда)
- [ ] Откат к поставочным весам — требование обратимости из ADR-0005
- [ ] Корпус технической русской речи из внешнего источника; перепроверить на нём кандидата 1
