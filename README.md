# AISwitcher

Переключатель раскладки, который понимает контекст, а не только словарь.

Классические переключатели (Punto Switcher, Caramba Switcher) сравнивают набранное слово со
словарём и таблицами невозможных буквосочетаний. Это отлично работает на `ghbdtn` → `привет` и
системно ломается на техническом тексте, именах собственных и коротких токенах — там, где
пользователь получает ложное переключение и в итоге выключает программу.

AISwitcher решает ровно этот класс ошибок: решение принимается по окружению токена, а не только
по самому токену.

**Статус: проектирование.** Кода пока нет — есть зафиксированная архитектура и план
исследования.

## Ключевые решения

- **[ADR-0001](docs/adr/ADR-0001-two-tier-detection-pipeline.md) — двухуровневый конвейер.**
  Дешёвый детерминированный слой закрывает большинство случаев за суб-миллисекунду; модель
  вызывается только там, где он не уверен. Латентность продукта не зависит от выбора модели.
- **[ADR-0002](docs/adr/ADR-0002-model-selection-for-context-disambiguation.md) — модель не
  выбрана.** `multilingual-e5-small` — кандидат, а не решение: это retrieval-модель, её целевая
  функция не совпадает с задачей, и она обязана выиграть у baseline на замерах.
- **[ADR-0003](docs/adr/ADR-0003-windows-input-interception.md) — Windows, RU/EN, локально.**
  Ввод не пишется на диск и не покидает машину.

## Принципы

- Локально и офлайн. Никаких облачных инференс-API.
- Ложное срабатывание дороже пропуска — при неуверенности программа молчит.
- Модель не на горячем пути.
- Любое автопереключение откатывается одной клавишей.
